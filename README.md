# Accra–Kumasi Bus Game

Drive the STC coach from Accra to Kumasi in your browser. Supports keyboard, mouse, and phone touch controls.

## Publish on GitHub Pages

Upload the contents of this folder to the root of a GitHub repository. In Settings → Pages, choose Deploy from a branch, main, and / (root), then Save. GitHub displays the playable website address once deployment completes.

No custom domain is required. This copy omits the original CNAME so it can use the default github.io address.

## Controls

W / Up: accelerate; S / Down: brake and reverse; A / D or Left / Right: steer; Space: brake; V: change view. Phones show touch controls automatically.

Internet access is needed to load three.js and the model decoder from jsDelivr. The assets folder must stay alongside index.html and game.js.
